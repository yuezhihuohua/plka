# Plka v0.6.1 · Mac 使用说明

安装到“应用程序”，从程序坞打开自己的设计参考图库。

## 安装 Plka

1. 按芯片选择 Apple 芯片 arm64 或 Intel x64 的 DMG，双击打开。
2. 将 **Plka.app 拖到 Applications（应用程序）**，等复制完成，再从“应用程序”打开 Plka。
3. 图库会在独立窗口中打开。可右键程序坞图标，选择“选项 → 在程序坞中保留”。
4. 安装完成后可以推出 Plka 安装磁盘，删除 DMG；日常直接打开应用程序中的 Plka。

桌面版要求 macOS 13 或更新版本。应用包含本地完整性签名，尚未 Apple 开发者签名和公证；首次运行可能被系统提示确认。确认来源后，按 [Apple 首次打开说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac) 操作。

## 跟随新手引导启用收藏

全新图库会显示引导；也可在左侧“新手引导 / 安装收藏”、顶部“网页收藏设置”，或 Mac 顶部“帮助 → 安装网页收藏”重新打开。

### 油猴试用版

1. 在 Chrome 安装 Tampermonkey（已有可跳过），在该扩展详情中开启“允许用户脚本”；较早 Chrome 使用开发者模式。
2. 回到 Plka 引导，点击“安装 Plka 油猴脚本”，在油猴安装页确认。脚本从本机提供，不需要找文件夹。
3. 保持 Plka 打开，或自行点击“开启登录后后台运行”。不开启时，每次登录电脑后先打开一次 Plka；油猴不能沿用独立扩展的自动唤醒通道。
4. 点击“打开收藏测试页”，悬停一张图片，点“收藏到 Plka”，在本地窗口选择或新建收藏夹并确认。下载时保留原网页。可点“检查脚本是否生效”；它检测油猴脚本，不把 Chrome 扩展未检测到误报为安装失败。

Pinterest、小红书、花瓣上有悬停收藏与“收集本页”（最多 30 张已加载图片）。首次按油猴提示允许访问图片域名及本机；全部成功后显示居中结果，并尝试自动关闭收藏页，若浏览器不允许自动关闭，可点击“打开图库”或自行关闭。部分失败保留失败项重试，已成功项不重复提交。

### Chrome 扩展版

引导中点击“打开扩展文件夹”。Chrome 地址栏输入 chrome://extensions，启用开发者模式，点击“加载已解压的扩展程序”，选择 ChromeExtension 文件夹。只需一次，以后 Chrome 自动唤醒图库，无需连接码和 Start 脚本；可悬停、右键收藏，或工具栏扫描当前页。Mac 网页入口优先打开独立窗口。

点击“收集本页”后会立即显示居中提示，等待你选图时按钮保持可用；如果选图页没有自动出现，请点提示中的“打开图片选择页”。连接超过 8 秒会显示重试入口，也可取消本次收藏。

两种入口共用同一图库。油猴网页入口目前打开浏览器图库；独立扩展保留 Mac 桌面窗口唤醒。从 v0.3.x 升级扩展，需要替换为固定身份版；v0.4 及以后沿用原扩展目录重新加载。

## 窗口与退出

点击左上角红色关闭按钮，隐藏图库窗口并继续后台运行。顶部菜单栏保留 Plka 的单色 P 小图标；点击它可打开图库、导入图片、安装网页收藏或退出。Chrome 收藏继续工作。

菜单栏选择“退出 Plka”或按 Command Q，退出桌面程序并停止当前图库服务。Chrome 下次使用收藏功能时仍可自动唤醒本机图库；再次启动 Plka 沿用原图库。后台运行时会检查图库服务状态，意外停止后尝试自动恢复。

Command O 导入图片，Command Shift N 新建收藏夹，Command K 搜索，Command R 刷新图库，Command W 关闭窗口。复制 Codex 指令使用系统剪贴板。来源网页在默认浏览器中打开，Markdown 报告通过系统保存窗口下载。

## 旧版升级与图库保护

先在旧版“图库与备份”创建完整备份。退出旧的 Plka 桌面界面，将新版 Plka.app 拖入“应用程序”，选择替换后重新打开。

应用会复用已记录的图库，也可识别正在运行的旧版图库；启动新版前只退出凭据匹配的旧服务，并创建升级前快照。不同图库或其他程序占用端口时，不接管。

**应用与图片分别保存。替换 Plka.app 不会删除图库。**图库沿用原路径，不自动搬移图片；原图库若仍在旧程序的 data 中，请保留该 data 目录，确认实际路径并完成备份后再清理旧文件夹。

全新安装图库位于 ~/Library/Application Support/Plka/library。实际路径以“图库与备份”为准。程序内部助手、扩展和日志在同级 app、ChromeExtension、logs；无需日常打开这些文件夹。

## 用自己的 Codex 分析

在图库“Codex 分析设置”点一次“安装到本机 Codex”，然后在自己的本机 Codex 发送：

> $reference-library 分析“包装设计”收藏夹，逐张查看图片，比较配色、构图与材质，并把报告保存回 Plka。

无需填写模型 API Key。分析使用自己的账号、网络和额度；所选图片与备注会交给当前模型。无法访问这台电脑文件的云端环境不能直接使用本地 Skill。

## 管理与备份

删除收藏夹时，共享图片保留，独占图片进回收站。回收站可恢复、单张、多选或全部永久删除。永久删除不可撤销，独立备份保留。

“图库与备份 → 创建本地备份”保存数据库、图片、报告和内部访问凭据。恢复时先停用扩展并停止服务，保留现有图库供回退，再选择备份目录。不要将个人图库、凭据和安装后的 Skill 配置上传 GitHub。

## 验证与首次检查

Apple 芯片包使用隔离图库检验原生窗口、真实 WebKit 图库渲染、图片保存与重启保留、本机助手和 Skill 接口。各包的运行环境校验.json 记录具体结果；Intel 的原生验收状态单独列出。

首次建议收藏一张测试图，在独立窗口确认可见，关闭并重新打开 Plka，确认图片仍在，再用自己的 Codex 分析。版本 0.6.1 · 2026-10-18。
