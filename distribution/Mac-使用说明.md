# Plka v0.3.2 · Mac 使用说明

为设计参考而做的独立本地图库。包内自带运行环境，无需安装 Node.js，也不需要单独购买 Eagle。请在能正常使用 Chrome 和本机 Codex 的 Mac 上使用。

## 先选对版本

苹果菜单 → 关于本机：显示“芯片 Apple M…”选择 **arm64 / Apple 芯片版**；显示“处理器 Intel…”选择 **x64 / Intel 版**。

内置 Node 22 的运行要求为 macOS 11 或更新版本；Chrome 和 Codex 还需满足各自的系统要求。两个包功能相同，只需使用对应芯片的一份。完整解压后，将整个文件夹放到固定位置，例如“文稿/Plka”。不要只移动其中的文件。

## 第一次使用，完成这四步

1. 双击 `1-Start.command`。短暂出现终端窗口，服务就绪后会打开 Chrome 中的 [Plka 图库](http://127.0.0.1:47831/)。出现“Plka 已就绪”后可以关闭终端，图库仍在后台运行。退出浏览器也不会停止服务；重启电脑后需再启动一次。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”，点击“加载已解压的扩展程序”，选择本包的 `extension` 文件夹。可先双击 `4-Open-Extension-Folder.command` 找到它。安装后将 **Plka · 网页收藏** 固定到工具栏。
3. 在图库的“连接与备份”复制连接码，点 Chrome 工具栏的 Plka 图标，粘贴并点击“连接 Plka”。连接码属于你自己的图库，不需要发给分享者。
4. 双击 `2-Install-Codex-Skill.command`，安装到当前 Mac 用户的 Codex。打开自己的本机 Codex，在新消息输入 `$reference-library`；没有出现时重启 Codex。也可从图库里的“Codex Skill”入口安装。

这个便携版尚未经过 Apple 开发者签名和公证。下载或接收后，macOS 可能拦截首次运行；请确认文件来自你信任的同事，再按系统的“隐私与安全性”提示处理，具体见 [Apple 首次打开说明](https://support.apple.com/zh-cn/guide/mac-help/mh40616/mac)。若提示文件损坏，先重新下载并完整解压；公司设备受管理时联系管理员。无需关闭系统安全保护。

## 包里各入口的用途

| 文件 | 用途 |
| --- | --- |
| 1-Start.command | 后台启动，并打开图库；已运行时复用服务 |
| 2-Install-Codex-Skill.command | 安装或更新当前用户的配套 Skill |
| 3-Stop.command | 停止与你的图库凭据匹配的后台服务 |
| 4-Open-Extension-Folder.command | 在访达中找到 Chrome 扩展目录 |
| 5-Open-Library-Data.command | 在访达中打开实际保存图片的图库目录 |
| 6-Connect-Existing-Library.command | 连接旧版 data 或完整备份目录 |
| 使用说明.html | 双击即可查看的完整离线说明 |

本包不自动添加登录启动项，也不包含分享者的图片、连接码、账号或个人 Codex 配置。

## 收藏图片和整理

Pinterest（包括 ph.pinterest.com）、小红书、花瓣：鼠标放到图片上，点击 **＋ 收藏到 Plka**；也可右键图片收藏，或从工具栏扫描当前页已加载的图片，选择多张一起保存。

采集窗口中选择或新建收藏夹，按需填写笔记。标签平时为灰色，点选后亮起，支持多选、自定义添加和管理候选标签。全部收藏成功后，窗口中央显示结果，约 1.8 秒后关闭采集窗口；部分失败时保留窗口供重试。原网站不会关闭。

支持的网站右侧有 **Plka · 打开图库** 悬浮入口，点击可切回已有图库标签页；可拖动改变高度，点 × 临时隐藏。其他网页先点一次扩展图标，或在扩展中勾选“所有网页显示入口”并按 Chrome 提示授权。浏览器设置页、扩展商店等受限制页面不能显示。

图片按原始宽高比例展示，不统一裁成方块；图库顶部可以调整显示密度。详情侧栏可编辑笔记和标签。下载以网站实际提供的图片为准，无法下载时可保存到本机后拖入图库。页面扫描最多显示 300 张已加载图片。

## 用自己的 Codex 分析

在本机 Codex 发送：

> $reference-library 分析“包装设计”收藏夹，逐张查看图片，比较构图、配色、字体和材质，归纳可借鉴的设计方向，并把报告保存回 Plka。

图库中的“用 Codex 分析”会准备并复制指令，需要粘贴到自己的 Codex 发送。Skill 调用名保留 `$reference-library`，界面显示名为 Plka分析。分析完成的报告可在图库查看与下载。

收藏和浏览使用本机服务；Codex 分析需要网络、自己的账号及额度，所选图片和备注会提交给当前模型。仅网页端、无法读取这台 Mac 文件的云端环境不能直接使用此本地 Skill。Codex 如提示访问本机服务或图片文件，需要按提示授权。

Skill 离线时可以尝试唤起已绑定的本地服务。移动程序文件夹后，要从新位置重新运行入口 2；无需把分享者的 Codex 设置导入自己的电脑。

## 图片保存在哪里

全新用户默认目录：`~/Library/Application Support/Plka/library`。双击入口 5 可以直接打开，无需手动寻找隐藏的资源库目录。实际路径以“连接与备份”显示为准。

图片、数据库和报告保存在该目录；程序更新不会主动删除它。路径记录位于 `~/Library/Application Support/Plka/library-location.json`，启动日志位于同级的 `logs` 文件夹。

已有旧版图库的用户，程序可能继续使用原来的 data 目录，不会自动搬家。**不要因为换新版就删除旧程序目录，先确认实际数据位置并备份。** 原图库路径不可用时会报错，不会创建一个空图库替代。

## 删除与备份

- 删除收藏夹：独占图片移入回收站；同时属于其他收藏夹的图片继续保留。收藏夹本身暂不提供恢复。
- 回收站：支持恢复、单张永久删除、多选删除、选择当前批次和清空全部。清空全部包含未加载或未匹配搜索的图片，确认框会显示总数。永久删除无法撤销。
- 连接与备份 → 创建本地备份：保存数据库、图片、报告和连接凭据的完整快照。备份不会随回收站清空而删除，请自行妥善保管。

恢复或连接旧图库：先停止原服务，运行入口 6，将包含 `library.sqlite` 的原 data 文件夹或完整快照目录拖入终端并回车，再运行入口 1，随后重装 Skill。不要把旧数据库的 WAL/SHM 文件混进备份。没有连接凭据的旧备份恢复后，需要重新配对扩展。

## 以后怎样更新

1. 先创建完整备份，使用旧版入口 3 停止服务。
2. 保留原数据目录，将新程序完整解压到固定位置，再启动新版。首次升级会在原图库下额外创建升级前快照，大图库需要相应的时间和磁盘空间。
3. Chrome 扩展建议在原 extension 目录覆盖后点击“重新加载”，再刷新网页。加载另一个目录可能成为另一份扩展，需要重新连接。不要同时保留两份活动扩展。
4. 从新程序目录运行入口 2，更新 Skill 的程序和运行环境路径。旧图库仍在旧程序目录内时，迁移数据前请保留旧目录。

## 遇到问题

| 情况 | 处理 |
| --- | --- |
| 提示 CPU / Bad CPU type | 检查“关于本机”，换用对应芯片的压缩包 |
| 点击悬浮按钮出现启动引导 | 先运行入口 1，再点“已启动，打开图库” |
| 启动时提示已有版本占用 | 用旧版入口 3 停止，再启动新版；不要同时运行两份图库服务 |
| 收藏失败或连接码不对 | 打开当前图库重新复制连接码，再连接扩展 |
| 网页没有收藏按钮 | 重新加载扩展并刷新网页；网站变化可能需要兼容更新 |
| Codex 找不到 Skill | 运行入口 2，检查是否为本机 Codex，并重启 Codex |
| 想找图片或启动日志 | 入口 5 打开图库；日志位于 `~/Library/Application Support/Plka/logs` |
| 想退出服务 | 运行入口 3；只关闭图库网页不会停止后台服务 |
| 提示无权运行脚本 | 用访达或系统自带归档工具重新完整解压 ZIP，保留文件权限；请勿只复制脚本 |

## 验证范围

每个包的 `运行环境校验.json` 记录 Node 官方下载来源、SHA-256、芯片类型和本机测试状态。对应本机芯片的包会执行真实启动、保存测试图、停止、重启保留、Skill 安装与报告回写测试；其他芯片包只验证官方校验值、Mach-O 架构和打包完整性。

收件人电脑上的首次安全提示、Chrome 扩展安装与真实模型分析仍需首次验收。建议先收藏一张测试图，重启确认存在，再用自己的 Codex 分析一次。
