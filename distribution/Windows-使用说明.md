# Plka v0.7.0 · Windows 使用说明

适用 Windows Intel / AMD 64 位电脑与 Chrome 浏览器。收图不需要 Codex；需要 AI 分析时，再连接自己的本机 Codex。安装包已包含运行环境，不用另外安装 Node.js。

**Windows 版在 Chrome 中显示图库，图片实际保存在电脑里。**首次安装后，服务在后台运行，不需要一直留着黑色命令窗口，也不用手填连接码。

## 1. 下载并解压

1. 打开 [Plka v0.7.0 版本下载页](https://github.com/yuezhihuohua/plka/releases/tag/v0.7.0)，展开 **Assets（附件）**。
2. 下载 **`Plka-Windows-x64-v0.7.0.zip`**。不要选 Source code，也不用下载 Mac 包；普通安装不需要打开 `.sha256` 校验文件。
3. 在 Windows 中右键 ZIP → **全部解压缩**，再打开解压后的文件夹。不要在压缩包预览中直接运行安装文件。

## 2. 首次启用 Plka

1. 双击解压文件夹中的 **`1-Install-Plka.cmd`**，不要先点 `1-Start.cmd`。
2. 等待安装完成：窗口显示 **“Plka 已启用”**，浏览器打开图库的新手引导。此时可以按窗口提示结束并关闭安装窗口。
3. 如果默认浏览器不是 Chrome，将 `http://127.0.0.1:47831/setup` 复制到 **Chrome 地址栏**打开，接下来的收藏入口在 Chrome 中安装。

程序安装在当前用户的 `%LOCALAPPDATA%\Plka` 下，无需管理员安装。这里的 `%LOCALAPPDATA%` 是 Windows 路径变量，可直接粘贴到文件资源管理器地址栏并回车。安装器会准备好程序和扩展目录，但 **还需要完成下面的浏览器安装步骤**。

## 3. 选择一种网页收藏入口

两种方式任选一个，先不要同时启用，避免网页上出现两套按钮。

| 方式 | 适合谁 | 首次要做什么 | 重启电脑后怎样使用 |
| --- | --- | --- | --- |
| 油猴版：建议先试用 | 希望在原网页完成图片选择和收藏 | 安装 Tampermonkey 和 Plka 脚本 | 开启 Plka 的“登录后后台运行”；未开启则先运行一次 `1-Start.cmd` |
| 独立 Chrome 扩展 | 需要原生右键收藏、Chrome 自动唤醒图库 | 开启开发者模式，加载指定文件夹 | 打开 Chrome，使用 Plka 即可自动唤醒，无需每天运行 Start |

### 方式 A：油猴版

1. 在图库左侧点 **“新手引导 / 安装收藏”**，找到“通过 Tampermonkey 收藏”。首次安装通常已自动打开此引导。
2. 点 **“安装 Tampermonkey”**，选择 Chrome，按页面提示进入扩展商店并添加到 Chrome。已装油猴可跳过此步。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并回车，找到 **Tampermonkey → 详情 → 开启“允许用户脚本”**。较旧的 Chrome 没有此开关时，可按 [油猴官方说明](https://www.tampermonkey.net/faq.php#Q209) 处理。
4. 回到 Plka 新手引导，点 **“安装 Plka 油猴脚本”**，在 Tampermonkey 确认页点 **“安装”**。装好 Tampermonkey 后仍要安装这份 Plka 脚本。
5. 在同一引导中点 **“开启登录后后台运行”**。这会让 Plka 在下次登录 Windows 时自动运行；本次安装已经启动服务，不必重启。油猴本身不能唤醒完全停止的 Plka；不想开启登录启动时，重启电脑后先双击 `1-Start.cmd` 即可。
6. 关闭安装窗口、刷新准备收藏的网页，再按下一节试收一张图片。首次下载时，若油猴询问是否允许访问图片域名或本机图库，按提示允许本次收藏所需的访问。

油猴版支持 Pinterest、小红书、花瓣及 Plka 测试页。图片悬停收藏和“收集本页”均在当前网页操作；不提供 Chrome 原生右键菜单。

### 方式 B：独立 Chrome 扩展

1. 完成上面的 Plka 首次安装后，在 Chrome 地址栏输入 `chrome://extensions` 并回车。
2. 打开页面右上角 **“开发者模式”**。
3. 点 **“加载已解压的扩展程序”**。在文件夹选择窗口的地址栏粘贴 **`%LOCALAPPDATA%\Plka\ChromeExtension`**，回车进入，再点 **“选择文件夹”**。
4. 看到 **Plka** 扩展卡片并确认已启用，然后刷新要收藏的网站。需要工具栏入口时，可在 Chrome 右上角拼图图标中固定 Plka。

选择的是安装器准备的 **ChromeExtension** 文件夹，不是整个 Windows 解压包、ZIP，也不是 `4-Open-Extension-Folder.cmd` 打开的旧扩展目录。使用此方式不要求开启登录启动，Chrome 会通过本机助手自动唤醒图库。

## 4. 试收第一张图

1. 在 Plka 引导点 **“打开收藏测试页”**，将鼠标放到图片上。
2. 点 **“收藏到 Plka”**，选择或新建收藏夹，再点确认收藏。标签和备注按需填写，第一次可以先跳过。
3. 等待成功提示。油猴版在当前网页显示收藏弹层，成功后约 1.4 秒收起；独立扩展打开的采集窗口成功后约 1.8 秒关闭。原网站不会关闭，部分失败时可重试未保存的图片。
4. 点网页右侧 **“Plka · 打开图库”**，进入刚选的收藏夹，确认图片已经出现。

完成这一步后，即可到 Pinterest、小红书、花瓣按相同方式收图。油猴下载期间请保留原网页。收藏时会记住上次成功使用的收藏夹。

## 日常收藏

**用油猴版：**启用登录后台运行后，登录 Windows → 打开 Chrome → 浏览网站 → 悬停图片收藏即可。关闭图库标签页不会停止后台服务；手动停止服务后，需要重新启动，油猴不能自动唤醒。

**用独立扩展：**打开 Chrome → 悬停或右键图片收藏；也可点击工具栏的 Plka 扫描本页。服务未运行时，扩展会尝试自动唤醒。

**打开图库：**点网页右侧 **“Plka · 打开图库”**；独立扩展还可以点工具栏中的 **“打开 Plka 图库”**。已在后台运行时，也可以在 Chrome 打开 `http://127.0.0.1:47831/`，建议收藏为书签。关闭这个标签页后仍可继续收图，无需留着命令窗口。

**批量收藏：**油猴版点网页浮动入口的“收集本页”，在当前页面选择图片和收藏夹，最多 30 张已加载图片。独立扩展可通过工具栏扫描，最多 300 张。连接超过 8 秒会提示重试，油猴弹层可关闭或按 Escape 取消。

单图最大 16 MB，画质以实际下载文件为准。图库按原比例显示图片，可搜索、加备注、点选标签，并将同一张图片放入多个收藏夹。网页浮动入口可拖动和临时隐藏；Chrome 设置页、扩展商店等受限页面无法显示此入口。

## 在 Codex 中分析收藏夹

这是可选功能，先成功收图再设置即可。

1. 在图库左侧点 **“Codex 分析设置” → “安装到本机 Codex”**，等待安装成功。若自己的 Codex 没有识别到 Skill，重新打开 Codex 再试。
2. 选中要分析的收藏夹，点 **“用 Codex 分析”**，填写关注点，再点 **“复制分析指令 → 到 Codex 发送”**。
3. 切换到这台电脑上自己的 Codex，粘贴并发送。分析结束后回到图库左侧 **“分析报告”** 查看。

也可以直接在本机 Codex 发送：

> $reference-library 分析“商业街入口”收藏夹，逐张查看图片，比较尺度、材质、灯光与招牌，并将报告保存回 Plka。

使用自己的账号、网络和额度；所选图片与备注会交给模型。不需要在 Plka 填模型 API Key。只使用不能读取本机文件的云端环境，无法直接使用这个本地 Skill。

## 解压包里的文件分别做什么

| 文件 | 什么时候用 |
| --- | --- |
| `1-Install-Plka.cmd` | 首次安装、更新或修复安装，普通用户先点这个 |
| `1-Start.cmd` | 备用启动入口；油猴版未开启登录启动时，重启后用它启动后台服务 |
| `2-Install-Codex-Skill.cmd` | 备用 Skill 安装入口，日常优先使用图库内的安装按钮 |
| `3-Stop.cmd` | 维护时停止图库服务；收藏期间不要运行 |
| `4-Open-Extension-Folder.cmd` | 旧入口，打开解压包内的 extension；新安装请加载 `%LOCALAPPDATA%\Plka\ChromeExtension` |
| `5-Enable-Autostart.cmd` / `6-Disable-Autostart.cmd` | 旧版登录启动入口，依赖解压目录；新安装优先用新手引导中的登录启动开关，不要重复设置 |
| `7-Connect-Existing-Library.cmd` | 原图库位置改变或需要连接旧图库时使用 |
| `使用说明.html` / `使用说明.md` | 离线操作说明；[在线说明](https://github.com/yuezhihuohua/plka/blob/main/distribution/Windows-使用说明.md) 随维护更新 |
| runtime、tools 等文件夹 | 安装和运行所需文件，不必逐个打开或单独移动 |

## 数据与备份

在图库左侧 **“图库与备份”** 查看实际存储路径并创建完整备份。全新安装的默认路径如下，可直接粘贴到文件资源管理器地址栏打开：

| 内容 | 默认位置 |
| --- | --- |
| 图库：图片、收藏夹索引、报告、备份 | `%LOCALAPPDATA%\Plka\library` |
| 安装后的程序 | `%LOCALAPPDATA%\Plka\app` |
| Chrome 扩展 | `%LOCALAPPDATA%\Plka\ChromeExtension` |
| 运行日志 | `%LOCALAPPDATA%\Plka\logs` |

安装后的程序与新图库位于用户目录中，不依赖原 ZIP。但先不要删除旧版解压目录：**老用户的图库可能仍在原文件夹的 data 里**，旧启动项或 Skill 也可能指向原目录。以“图库与备份”显示的实际位置为准。

删除收藏夹时，其他收藏夹共享的图片仍保留；仅属于该收藏夹的图片进回收站。回收站可恢复、单张、多选或全部永久删除，独立备份不受影响。

## 从旧版升级

1. 在旧图库创建完整备份，记下“图库与备份”中的实际路径，保留原数据目录。
2. 完整解压新版，再运行 **`1-Install-Plka.cmd`**。安装器会复用原图库路径，或识别正在运行的旧版；升级前保存完整快照，不自动搬移图片。
3. 油猴版回到新手引导重新安装 Plka 脚本；独立扩展版在 `chrome://extensions` 中找到 Plka，点重新加载，再刷新网页。v0.3.x 升级需要先移除旧扩展，再从 `%LOCALAPPDATA%\Plka\ChromeExtension` 加载固定身份的新版，避免两份同时启用；移除扩展不会删除本机图库。
4. 确认原图片和收藏夹仍在，按需在“Codex 分析设置”更新 Skill，再试收一张图。

如果提示原图库路径不可用，先连接原图库，不要用空图库覆盖。切勿直接删除 `data`、`library` 或数据库文件。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 不知道先点哪个文件 | 完整解压后先双击 `1-Install-Plka.cmd`；安装完成再选择一种浏览器收藏入口 |
| 安装后没有打开引导 | 先检查安装窗口是否报错；显示成功后，在 Chrome 输入 `http://127.0.0.1:47831/setup`；仍打不开则查看 `%LOCALAPPDATA%\Plka\logs` |
| 只装了 Tampermonkey，网页没有按钮 | 还需安装 Plka 油猴脚本、开启“允许用户脚本”，再刷新目标网页 |
| 油猴提示图库未运行 | 双击 `1-Start.cmd` 后重试；在新手引导开启“登录后后台运行”，减少下次手动启动 |
| 独立扩展提示首次启用助手 | 重新运行 `1-Install-Plka.cmd`，确认加载的是 `%LOCALAPPDATA%\Plka\ChromeExtension`，再重新加载扩展并刷新网页 |
| 关闭黑色窗口会影响使用吗 | 安装成功后的提示窗口可以关闭；新版服务在后台运行。旧版写着“关闭窗口会停止服务”的前台窗口，请先完成新版安装 |
| 旧版还有连接码输入框 | 改用新版入口；独立扩展需要替换成固定身份的新版，不要同时启用两份 |
| 收藏一直转圈或图片失败 | 等待连接错误提示后重试；油猴下载期间保留原网页，并检查油猴是否弹出域名访问确认；网站登录或防盗链也可能影响下载 |
| 想完全停止后台运行 | 在引导关闭登录启动，禁用浏览器中的 Plka 脚本或扩展，再运行 `3-Stop.cmd`；否则独立扩展可能再次唤醒服务 |
| 系统或公司策略阻止安装、本机通信 | 保留提示信息，受管理电脑联系管理员；不需要关闭安全软件或放宽整台电脑的权限 |

## 验证范围

Windows 包已校验运行环境的官方 SHA-256、x64 架构、归档完整性和中文文件名，自动测试覆盖安装清单、通信协议、权限和数据保留。Windows 隐藏启动、本机通信注册与真实 Chrome 启动仍需 Windows x64 原生验收。建议先完成测试页收藏，并在重启后确认图片保留，再大量使用。
