# Plka v0.3.2 · Windows 使用说明

适用：Windows 10/11，Intel / AMD 64 位，Chrome，本机 Codex 桌面应用或 CLI。

这是本地部署的开发试用版。包内自带运行环境，无需安装 Node.js。收藏、图库浏览、备份均在本机完成；Codex 分析使用自己的账号和额度，需要联网。

## 你会收到什么

| 文件 | 用途 |
| --- | --- |
| 1-Start.cmd | 后台启动 Plka 并打开图库，无需保留黑色窗口 |
| 2-Install-Codex-Skill.cmd | 安装或更新配套 Skill |
| 3-Stop.cmd | 停止与你的图库凭据匹配的后台服务 |
| 4-Open-Extension-Folder.cmd | 打开 Chrome 扩展文件夹 |
| 5-Enable-Autostart.cmd | 可选：登录 Windows 时自动在后台启动 |
| 6-Disable-Autostart.cmd | 取消开机启动 |
| 7-Connect-Existing-Library.cmd | 连接旧版 data 文件夹或恢复后的图库 |
| 使用说明.html | 可直接打开的完整使用说明 |

包内不含制作者的图片、连接码、账号或 Codex 配置。

## 第一次使用

1. 完整解压到固定位置，例如“文档\Plka”。不要直接在 ZIP 中运行。
2. 双击 `1-Start.cmd`。启动入口会在服务就绪后关闭，浏览器打开 [Plka](http://127.0.0.1:47831)。后台服务仍在运行，关闭浏览器不会停止它。
3. 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择本包的 `extension` 文件夹，并将 **Plka · 网页收藏** 固定到工具栏。
4. 在 Plka 的“连接与备份”复制连接码，打开扩展并粘贴，点击“连接 Plka”。
5. 双击 `2-Install-Codex-Skill.cmd`，或在图库的“Codex Skill”入口安装。下一轮消息输入 `$reference-library`；列表未更新时重启 Codex。

想省去每次开机后的手动启动，可运行一次 `5-Enable-Autostart.cmd`。它只添加当前用户的启动快捷方式，不需要管理员权限；取消时运行 `6-Disable-Autostart.cmd`。启用后不要移动程序文件夹，移动后需从新位置再次启用。

本地服务必须在后台运行，才能保存和读取本机图片。现在可以隐藏运行窗口，但它不是一个完全不需要服务的浏览器插件。

## 日常收藏

### 网页悬浮入口

Pinterest、小红书、花瓣页面右侧会显示带 Plka 标志的“打开图库”入口。点一下切回图库；已有图库标签页会复用，保留当前页面状态。可上下拖动调整位置，点 × 临时隐藏本页入口，刷新恢复。

其他网页可以先点击一次扩展图标启用当前页入口。想让普通网页自动显示，打开扩展，勾选“所有网页显示入口”，按 Chrome 提示允许网站访问。取消勾选后，普通网页的自动入口会移除；默认支持的网站仍保留。Chrome 设置页和扩展商店等受限制页面不能注入悬浮按钮。

扩展弹窗顶部也有“打开 Plka 图库”按钮。服务未运行时会打开启动引导页，启动后点重试即可；仍需本机后台服务运行。


- 鼠标悬停在 Pinterest、小红书、花瓣图片上，点击“＋ 收藏到 Plka”。
- 也可右键图片 → “收藏到 Plka”。
- 工具栏入口可以扫描当前页面已加载的图片，勾选多张后统一收藏。

收藏时选择或新建收藏夹，填写笔记，并点亮需要的标签。预设了日系、极简、排版、配色、品牌、包装、空间、材质、插画、摄影。未选标签为灰色，选中后显示柔和彩色；支持多选和自定义添加。

“管理”可移除可选标签，不会批量改写旧图片上的标签。修改某张图片的归属标签，打开详情、点亮或取消，再保存即可。主图库和采集窗口共享可选标签。

全部成功时，窗口中央显示收藏结果，约 1.8 秒后自动关闭采集窗口。部分失败时保留窗口和失败项，已成功的图片不会重复提交。自动关闭只针对采集窗口，不会关闭 Pinterest 等原网站。

页面扫描最多显示 300 张已加载图片。首次下载其他域名图片时，Chrome 可能请求所选域名权限。下载失败会显示原因，可手动保存后拖入图库。保存的分辨率以实际可下载文件为准。

悬停按钮未出现时，重新加载扩展并刷新网页。`ph.pinterest.com` 在支持范围内；网站变化可能需要兼容更新。

## 在 Codex 中分析收藏夹

例如：

> $reference-library 分析“商业街入口”收藏夹，比较尺度、材质、灯光和招牌关系，归纳设计方向，并将报告保存回图库。

界面里的“用 Codex 分析”会准备并复制指令，粘贴到自己的 Codex 发送后执行。Skill 的调用名继续保留 `$reference-library`，兼容已有安装。

Skill 建立固定图片清单，逐张读取和查看，比较共性与差异，并将带图片依据的报告写回“分析报告”。无法读取的图片会记录原因；可以继续未完成任务并下载 Markdown 报告。

本地服务离线时，Skill 可以尝试启动。若 Codex 限制本机连接，按提示允许本机访问。仅网页版或不能访问这台电脑文件的云端环境无法直接使用此本地 Skill。分析时，所选图片与备注会提交给当前模型。

## 删除与回收站

- 删除收藏夹：独占图片移入回收站，同时属于其他收藏夹的图片保留。
- 回收站支持恢复、单张永久删除、多选删除、选择已显示批次，以及清空整个回收站。
- 清空全部包含未加载或未匹配搜索的图片，确认框会给出总数。
- 永久删除无法撤销；独立备份不会同步删除。历史报告保留文字，并标记原图已删除。收藏夹本身暂不提供恢复。

## 更新、图库位置与备份

**从 v0.2 升级最稳妥的方法：**先在旧版“连接与备份”创建完整备份，运行旧版的 `3-Stop.cmd`，把新版程序文件覆盖到原位置，保留整个旧 `data` 文件夹，随后运行新版 `1-Start.cmd`。不要先删除旧程序目录。

新版会识别原位置的旧图库，或已有 Skill 绑定的图库，并记录路径；不自动搬移或删除原图库。首次升级前会额外创建包含数据库、图片、报告和连接凭据的快照，保存在原图库的 `backups` 下。大图库会需要更多时间和额外磁盘空间，备份失败则停止升级。

如果新版放在另一个文件夹，且没有自动找到旧图库，运行 `7-Connect-Existing-Library.cmd`，选择包含 `library.sqlite` 的原 `data` 文件夹；确认旧服务停止后再启动新版。不要拿一个新空图库代替原图库后删除旧目录。

全新用户默认保存在 `%LOCALAPPDATA%\Plka\library`，独立于程序目录。实际位置以“连接与备份”显示为准；路径记录位于 `%LOCALAPPDATA%\Plka\library-location.json`。原图库路径不可用时会报错，不会悄悄创建一个空图库。

Chrome 扩展在原目录更新后，去扩展管理页点击“重新加载”，再刷新网页。加载另一个目录可能成为另一份扩展并需要重新配对。随后重新运行 `2-Install-Codex-Skill.cmd`，将 Skill 绑定到新版程序。原扩展目录和连接码保持不变时无需重新配对。

手动备份：连接与备份 → 创建本地备份。完整快照包含数据库、图片、报告与连接凭据，请妥善保管。恢复时停止服务，将快照作为独立图库目录，通过入口 7 连接后启动；不要混入旧数据库的 WAL/SHM 文件。旧版备份若没有连接凭据，恢复后需要重新配对扩展。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 为什么还要运行服务 | 图片保存在本机，需要后台进程读写；现在无需保留黑色窗口，可选开机启动 |
| 启动失败 | 先用旧版停止入口停止旧服务，检查原图库路径及剩余磁盘空间，再试新版 |
| 想查看错误日志 | `%LOCALAPPDATA%\Plka\logs` |
| 想停止后台服务 | 运行 3-Stop.cmd；下次运行入口 1 或用 Skill 启动 |
| 找不到旧图片 | 查看实际图库路径；用入口 7 连接原 data，保留旧文件夹 |
| 更新后外观未变化 | 确认旧服务已停止，再启动新版；重新加载扩展并刷新网页 |
| Codex 找不到 Skill | 再运行入口 2，确认使用本机 Codex，然后重启 Codex |
| 扩展连接失败 | 先启动 Plka，复制当前图库的连接码重新配对 |
| 电脑是 ARM / 骁龙 | 本包供 Intel / AMD x64，ARM 需要对应构建 |

## 验证状态

自动化覆盖数据保留、升级前备份、路径绑定、标签持久化、删除与共享保留、回收站、HTTP 权限、Skill 安装和报告回写；浏览器验证新主界面和采集窗口。采集窗口的 Chrome API 在测试中模拟，本地导入走真实接口。

本包的 Node 运行环境来自官方发行包并进行 SHA-256 与 x64 架构校验。尚未在真实 Windows 电脑原生验收无窗口启动、开机启动和首次扩展安装。请先在对方电脑跑通“收藏 → 重启仍存在 → Codex 分析 → 报告回写”，再大量使用。
