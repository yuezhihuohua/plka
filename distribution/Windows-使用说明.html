适用 Windows Intel / AMD 64 位 + Chrome + 自己的本机 Codex。包内自带运行环境。

首次只需启用一次

  1. 完整解压，双击 1-Install-Plka.cmd，完成当前用户的本机助手安装。它会打开新手引导。
  2. 可以在引导中安装 Tampermonkey 并允许用户脚本，再点“安装 Plka 油猴脚本”；保持图库服务运行，或自愿开启登录后台运行。若选择独立扩展：Chrome 打开 chrome://extensions，开启“开发者模式”，点击“加载已解压的扩展程序”，选择安装器准备的 ChromeExtension 文件夹。
  3. 以后打开 Chrome，直接点图片收藏或网页悬浮入口打开图库。扩展自动唤醒图库和交换访问凭据，不需要手填连接码，也不需要每天运行 Start。

安装到当前用户目录，并注册当前用户的 Chrome 本机通信入口，无需管理员安装。使用的是 Chrome 原生通信，不依靠普通网页获取本地凭据。

从旧版升级

先在旧版创建完整备份，再运行新版安装入口。安装器复用原图库路径，或识别正在运行的旧版；只退出凭据匹配的旧服务，升级前保存完整快照，不接管其他服务。

v0.3.x 升级到 v0.6.0，需要这一次移除旧 Plka 扩展，再从助手打开的 ChromeExtension 加载新版，以固定扩展身份。移除扩展不会删除保存在本机的图库，但旧扩展的显示偏好可能重置。后续沿用固定身份和原扩展目录更新即可。

原图库仍在旧程序 data 内的用户，不要直接删除旧程序文件夹。实际路径以“图库与备份”为准；安装器不自动搬移或删除图片。

油猴版不会使用独立扩展的本机唤醒通道；需保持 Plka 运行或开启登录启动，入口打开浏览器图库，支持悬停及最多 30 张已加载图片。油猴下载时保留原网页；浏览器可能需要手动关闭成功页。

收藏与整理

Pinterest、小红书、花瓣图片上点击“＋ 收藏到 Plka”，或右键图片收藏；工具栏可多选当前页已加载图片。收藏时选择或新建收藏夹，填写笔记，点亮所需标签。

全部成功后显示居中提示并关闭采集窗口；部分失败时保留失败项供重试。原网站不关闭。图库保留原始宽高比，支持搜索、详情、标签与多收藏夹归属。

网页右侧的 Plka 入口支持拖动、本页隐藏和切回已有图库标签页。其他网页可在扩展中启用“所有网页显示入口”并允许 Chrome 权限。设置页、扩展商店等受限页面不能注入。单图最大 16 MB，扫描最多 300 张，画质以实际下载文件为准。

用自己的 Codex

在图库“Codex 分析设置”安装一次配套 Skill，然后在本机 Codex 发送：

$reference-library 分析“商业街入口”收藏夹，逐张查看图片，比较尺度、材质、灯光与招牌，并将报告保存回 Plka。

图库“分析收藏夹”按钮会复制指令，粘贴到自己的 Codex 发送后执行。分析需要网络、账号和额度；所选图片与备注会交给模型。只使用网页端或不能读取本机文件的云端环境无法直接使用本地 Skill。

数据与备份

全新图库默认在 %LOCALAPPDATA%\Plka\library；助手程序在同级 app，扩展在 ChromeExtension，日志在 logs。旧版可能继续使用原 data；“图库与备份”显示实际位置。

创建本地备份可保存数据库、图片、报告与连接凭据。删除收藏夹时共享图片保留，独占图片进回收站；回收站可恢复、单张、多选或全部永久删除。永久删除不可撤销，独立备份不受影响。

停止服务、安装 Skill、打开扩展和连接备份等旧入口仅作维护。普通收藏无需使用。停止后下次使用插件会再次唤醒；完全停用时先禁用 Chrome 中的 Plka 再停止服务。v0.4 不要求登录 Windows 自动启动，旧的可选登录启动项可用取消入口移除。

验证范围

运行环境校验官方 Node SHA-256 和 x64 架构，归档校验中文文件名与完整性。自动测试验证安装清单、协议、权限和数据保留；Windows 隐藏启动、本机通信注册与真实 Chrome 启动仍需 Windows x64 原生验收。请先试一张图并验证重启保留，再大量使用。
