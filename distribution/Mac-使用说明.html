一次启用，以后直接在 Chrome 收藏。无需手填连接码，无需每天启动脚本。

第一次使用

  1. 按芯片选择 Apple 芯片 arm64 或 Intel x64 包，完整解压。
  2. 双击 Plka.app。它会把本机助手和运行环境装到当前用户的 Plka 目录，沿用原图库，并打开图库与扩展文件夹。无需另装 Node.js，无需管理员安装。
  3. Chrome 地址栏输入 chrome://extensions，打开“开发者模式”，点“加载已解压的扩展程序”，选择刚打开的 ChromeExtension 文件夹。将 Plka 固定到工具栏。
  4. 现在直接收藏即可；访问凭据由插件与本机助手自动交换，不需要复制、填写或管理连接码。

内置运行环境需 macOS 11 或更新版本；Chrome 和 Codex 还需满足各自系统要求。本版有完整性签名，尚未 Apple 开发者签名和公证。首次运行可能被 macOS 提示确认，请确认来源后按 Apple 首次打开说明 操作。

已有旧版怎样升级

先在旧版创建完整备份，再双击新版 Plka.app。安装器优先复用已记录的图库，也能识别正在运行的旧版图库；启动新版前仅退出凭据匹配的旧服务，随后执行升级前快照。其他程序或另一图库占用端口时，不会接管。

从 v0.3.x 升级只需这一次替换扩展：旧版没有固定扩展身份，新版改为固定身份以实现自动连接。移除旧 Plka 扩展，再加载助手打开的新版 ChromeExtension 文件夹，并刷新原网页，避免同时启用两份。图片保存在本机数据库，移除旧扩展不会删除图库；原扩展中的显示位置等偏好可能需要重新设置。

原图库可能仍在旧程序的 data 中。确认“图库与备份”中的实际路径并备份后，再决定是否删除旧程序目录。安装器不会自动搬移或删除图片。

日常使用

打开 Chrome 时，Plka 扩展自动唤醒本机图库。点击网页悬浮入口打开图库；鼠标放到 Pinterest、小红书、花瓣图片上点击“＋ 收藏到 Plka”，或右键收藏。工具栏可扫描当前页已加载的图片，多选后统一收藏。

采集窗口选择收藏夹、笔记和标签，全部成功后中央提示并自动关闭采集窗口，原网站不会关闭。若后台意外停止，下次收藏或打开图库会尝试自动恢复。首次尚未安装助手时，显示一次启用引导，不显示连接码输入框。

网页悬浮入口可拖动、临时隐藏。其他普通网页可勾选“所有网页显示入口”并允许 Chrome 网站权限。浏览器设置页、扩展商店等受限制页面不能注入按钮。扫描最多 300 张已加载图片，单图最大 16 MB，分辨率以网站可下载文件为准。

程序不添加 Mac 登录启动项；由 Chrome 在需要时启动，因此不用每天寻找 Start 脚本。保持扩展启用且本机助手安装目录可用即可。

图库位置与备份

全新用户图库默认在 ~/Library/Application Support/Plka/library，旧用户可能继续用原 data。实际位置以“图库与备份”为准。

助手程序在 ~/Library/Application Support/Plka/app，扩展在同级 ChromeExtension，日志在 logs。本机通信配置保存在 Chrome 的 NativeMessagingHosts 目录。它只允许固定身份的 Plka 扩展获取访问凭据，普通网页仍不能读取图库私有接口。

“图库与备份”→“创建本地备份”保存数据库、图片、报告和连接凭据。不要删除图库里的 library.sqlite、assets 或 .connection-key，也不要把这些上传 GitHub。

用自己的 Codex

在图库“Codex Skill”点一次“安装到本机 Codex”，然后在自己的本机 Codex 发送：

$reference-library 分析“包装设计”收藏夹，逐张查看图片，比较配色、构图与材质，并把报告保存回 Plka。

无需给图库填写模型 API Key。分析使用自己的账号、网络和额度；所选图片与备注会交给当前模型。无法访问这台电脑文件的云端环境不能直接使用本地 Skill。

删除与恢复

删除收藏夹时，共享图片保留，独占图片进回收站。回收站可恢复、单张永久删除、多选删除或清空全部；永久删除不可撤销，独立备份保留。

恢复完整备份时先停止服务，保留现有目录供回退，再把备份作为独立图库连接。旧版备份缺少凭据时，助手可重新自动识别，不需要手填新码。

维护与退出

包内 .command 文件仅供维护：安装 Skill、停止服务、打开数据目录或连接备份。普通收藏无需运行它们。手动停止后，Chrome 下次使用 Plka 会重新唤醒；完全停用时在 Chrome 禁用 Plka 扩展后停止服务。

新版本仍手动更新：备份 → 启用新版 Plka.app → 在原 Chrome 扩展条目重新加载 → 更新 Skill。助手程序按版本保存，重复打开相同应用不会重复复制运行环境。使用者数据不包含在分享包中。

验证说明

Apple 芯片包在隔离 Mac 用户目录验证真实 App 入口、安装、离线本机通信启动、凭据自动交换、图片重启保留及 Skill 报告回写。各包的运行环境校验.json 记录具体结果。Intel 与 Windows 原生验收状态单独说明，不以 Mac 测试代替。
